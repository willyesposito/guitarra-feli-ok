# guitarra-feli

Dos apps de guitarra, servidas con GitHub Pages desde este repo.

- **Guitarra con Feli** (`/`): curso de 30 días para Feli, con las batallas del Tío Ale.
  https://willyesposito.github.io/guitarra-feli-ok/
- **Guitarra desde cero** (`/adulto/`): mismo motor, 30 sesiones para un adulto que empieza de cero.
  https://willyesposito.github.io/guitarra-feli-ok/adulto/

Cada una guarda su progreso por separado y funciona sin internet una vez abierta.
